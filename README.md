# DF-Workflow-Sat
This is a program to generate regular workflow reports every month from the AssesmentCaptureReport of Dhwani Foundation
It gives a clear picture of # docs submitted, # docs reviewed by Reviewers, # of docs accepted and rejected, # of Docs reviewed by each IM and trainers. 

To use download the full folder, open the folder in Terminal;

" pip install -r requirements.txt "

run with " python -m streamlit run app.py "
